MÓDULO I – TEORIA DOS CONJUNTOS

2.1. Conceitos Básicos

  • Conjunto: agrupamento de elementos com características comuns.
  • Pertinência: relação entre elemento e conjunto (∈ pertence, ∉ não pertence).
  • Inclusão: relação entre conjuntos (⊂ está contido, ⊄ não está contido).
  • Conjunto vazio (∅): não possui elementos.
  • Conjunto universo (U): conjunto que contém todos os elementos considerados.

📌 Exemplo: Se A = {1, 2, 3} e B = {1, 2, 3, 4}.

  • 1 ∈ A (1 pertence a A).
  • 5 ∉ A (5 não pertence a A).
  • A ⊂ B (A está contido em B).
  • B ⊄ A (B não está contido em A).

2.2. Operações com Conjuntos

  • União (∪): reunião dos elementos de dois ou mais conjuntos. Ex: A ∪ B = {1, 2, 3, 4}.
  • Interseção (∩): elementos comuns a dois ou mais conjuntos. Ex: A ∩ B = {1, 2, 3}.
  • Diferença ( - ): elementos que estão em um conjunto e não no outro. Ex: B - A = {4}.
  • Complementar: elementos do universo que não estão no conjunto. Ex: complementar de A em U.
  • Produto Cartesiano: conjunto de todos os pares ordenados (a, b) com a ∈ A e b ∈ B.

📌 Produto Cartesiano: Se A = {1, 2} e B = {a, b}.

  • A × B = {(1,a), (1,b), (2,a), (2,b)}.
  • B × A = {(a,1), (a,2), (b,1), (b,2)}.

⚠️ Atenção: A × B ≠ B × A (a ordem importa!).

⚡ Pegadinha: Confundir ∈ (pertence) com ⊂ (está contido). O primeiro é entre elemento e conjunto; o segundo, entre conjuntos.

MÓDULO II – CONJUNTOS NUMÉRICOS: NATURAIS E INTEIROS

3.1. Conjunto dos Naturais (N)

  • N = {0, 1, 2, 3, 4, ...}
  • Ordenação: 0 < 1 < 2 < 3 < ...
  • Operações: soma, subtração, multiplicação e divisão (com restrições).

3.2. Conjunto dos Inteiros (Z)

  • Z = {..., -3, -2, -1, 0, 1, 2, 3, ...}
  • N ⊂ Z (todo natural é inteiro).
  • Ordenação: ... < -3 < -2 < -1 < 0 < 1 < 2 < 3 < ...
  • Operações: todas as operações são fechadas (soma, subtração, multiplicação). A divisão pode não ser inteira.

📌 Exemplo: Em Z, a divisão de 5 por 2 não resulta em um inteiro (5 ÷ 2 = 2,5). Em N, a subtração de 3 por 5 não é possível (3 - 5 = -2, que não é natural).

3.3. Múltiplos e Divisores

  • Múltiplos de um número: resultado da multiplicação por um inteiro. Ex: múltiplos de 3: 0, 3, 6, 9, 12, ...
  • Divisores de um número: números que dividem exatamente. Ex: divisores de 12: 1, 2, 3, 4, 6, 12.
  • Números primos: têm exatamente dois divisores: 1 e ele mesmo. Ex: 2, 3, 5, 7, 11, 13, 17, 19, 23, ...
⚡ Pegadinha: O número 1 não é primo (tem apenas um divisor). O 2 é o único primo par.

MÓDULO III – CONJUNTOS NUMÉRICOS: RACIONAIS E REAIS

4.1. Conjunto dos Racionais (Q)

  • Q = { números que podem ser escritos na forma a/b, com a ∈ Z, b ∈ Z, b ≠ 0 }
  • Representação: frações, decimais finitos e dízimas periódicas.
  • Exemplos: 1/2 = 0,5; 1/3 = 0,333...; 2 = 2/1.
  • N ⊂ Z ⊂ Q.
  • Dízima periódica: decimal que se repete infinitamente. Ex: 0,333... (período 3), 0,121212... (período 12).

📌 Como transformar dízima em fração:

  • 0,333... = 3/9 = 1/3.
  • 0,121212... = 12/99 = 4/33.

4.2. Conjunto dos Reais (R)

  • R = Q ∪ {irracionais}
  • Irracionais: números que não podem ser escritos como fração. Ex: √2, π, √3.
  • N ⊂ Z ⊂ Q ⊂ R.
  • Operações com radicais: soma só é possível com radicais semelhantes. Ex: 2√3 + 5√3 = 7√3.
  • Propriedades: √(a × b) = √a × √b; √(a/b) = √a / √b.

📌 Exemplo de racionalização:

  • 1/√2 = (1/√2) × (√2/√2) = √2/2.
  • 2/(3+√5) = [2/(3+√5)] × [(3-√5)/(3-√5)] = 2(3-√5)/(9-5) = (6-2√5)/4 = (3-√5)/2.
⚡ Pegadinha: Dízimas periódicas são números racionais (podem ser escritas como fração). Números como √2, π são irracionais.

MÓDULO IV – DIVISIBILIDADE, MDC E MMC

5.1. Critérios de Divisibilidade

  • Por 2: número par (termina em 0, 2, 4, 6, 8).
  • Por 3: soma dos algarismos é divisível por 3.
  • Por 4: os dois últimos algarismos formam um número divisível por 4.
  • Por 5: termina em 0 ou 5.
  • Por 6: divisível por 2 e por 3.
  • Por 9: soma dos algarismos é divisível por 9.
  • Por 10: termina em 0.

5.2. Máximo Divisor Comum (MDC)

  • MDC: maior número que divide dois ou mais números.
  • Método: decomposição em fatores primos (pegar os fatores comuns com o menor expoente).
  • Exemplo: MDC(12, 18) = 6 (12 = 2²×3; 18 = 2×3²; comuns: 2×3 = 6).

5.3. Mínimo Múltiplo Comum (MMC)

  • MMC: menor número que é múltiplo de dois ou mais números.
  • Método: decomposição em fatores primos (pegar os fatores comuns e não comuns com o maior expoente).
  • Exemplo: MMC(12, 18) = 36 (12 = 2²×3; 18 = 2×3²; comuns e não comuns: 2²×3² = 36).

📌 Dica:

  • O MDC é útil para divisão de objetos em partes iguais.
  • O MMC é útil para encontrar um momento em que eventos coincidem (ex: encontro de pessoas, trens, etc.).
⚡ Pegadinha: Não confundir MDC com MMC. MDC usa os menores expoentes; MMC usa os maiores.

MÓDULO V – DICAS E PEGADINHAS

6.1. Dicas de Resolução

  • Leia com atenção: identifique se o problema envolve união, interseção, diferença ou complementar.
  • Desenhe diagramas: para conjuntos, use o diagrama de Venn para visualizar as relações.
  • Verifique a ordem: no produto cartesiano, a ordem dos elementos importa.
  • Frações e dízimas: lembre-se de que toda dízima periódica é uma fração.
  • MDC e MMC: use a decomposição em fatores primos para agilizar os cálculos.

6.2. Pegadinhas Comuns

  • Confundir ∈ e ⊂: elemento x pertence (∈) ao conjunto; conjunto A está contido (⊂) em B.
  • Esquecer o zero: o zero é natural? Sim (N = {0, 1, 2, ...}) na maioria das bancas. Verifique o edital.
  • 1 não é primo: ele tem apenas um divisor (ele mesmo).
  • Dízimas são racionais: 0,333... é racional (1/3).
  • √2 é irracional: não pode ser escrito como fração.
  • MMC de números primos: é o produto deles (ex: MMC(2,3,5) = 30).
💡 Dica Final: Pratique bastante com exercícios. A teoria dos conjuntos e os números são a base para tudo que vem depois. Domine bem este módulo!
