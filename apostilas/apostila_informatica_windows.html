🖥️ INFORMÁTICA – WINDOWS 10/11

Área de Trabalho, Menu Iniciar, Barra de Tarefas, Gerenciador de Tarefas, Janelas, Painel de Controle, Lixeira, Arquivos, Pastas e Atalhos

1. INTRODUÇÃO

O Windows 10/11 é o sistema operacional mais utilizado em ambientes corporativos e de concursos públicos. Dominar suas funcionalidades é essencial para a navegação, organização de arquivos e configuração do ambiente de trabalho.

Este módulo cobre os principais componentes do Windows: Área de Trabalho, Menu Iniciar, Barra de Tarefas, Gerenciador de Tarefas, Janelas, Painel de Controle, Lixeira e operações com arquivos e pastas.

🎯 Objetivo do Módulo: Dominar as funcionalidades do Windows 10/11, incluindo navegação, configuração, gerenciamento de arquivos e pastas, e atalhos de teclado, com 35 questões ao final.

MÓDULO I – ÁREA DE TRABALHO E MENU INICIAR

2.1. Área de Trabalho (Desktop)

  • Exibir: ícones, arquivos e pastas diretamente na tela.
  • Classificar: organizar ícones por nome, tamanho, tipo, data de modificação.
  • Atualizar: recarregar a exibição (F5 ou botão direito → Atualizar).
  • Resolução da tela: ajustar a qualidade da imagem (Configurações → Sistema → Tela).
  • Gadgets: (no Windows 7) eram miniaplicativos. No Windows 10/11, foram substituídos por widgets (ícone na barra de tarefas).

2.2. Menu Iniciar

  • Documentos, Imagens, Computador (Este Computador): atalhos para pastas do usuário.
  • Painel de Controle: central de configurações do sistema.
  • Dispositivos e Impressoras: gerenciar periféricos.
  • Programa Padrão: definir aplicativos padrão (navegador, player de música, etc.).
  • Ajuda e Suporte: acesso à documentação do Windows.
  • Desligar, Reiniciar, Suspender: opções de energia.
  • Todos os programas: lista de aplicativos instalados.
  • Pesquisar: barra de pesquisa integrada (Windows + S).
  • Ponto de Partida: no Windows 10, é o menu Iniciar; no Windows 11, centralizado.
💡 Dica: A tecla Windows (Win) abre o Menu Iniciar. Win + S abre a pesquisa.

MÓDULO II – BARRA DE TAREFAS E GERENCIADOR DE TAREFAS

3.1. Barra de Tarefas

  • Localização: geralmente na parte inferior da tela.
  • Propriedades: clicar com o botão direito → "Configurações da Barra de Tarefas" ou "Propriedades".
  • Opções:
    • Bloquear/desbloquear a barra de tarefas.
    • Ocultar automaticamente.
    • Usar botões pequenos.
    • Posição na tela (inferior, superior, esquerda, direita).
  • Área de notificação: relógio, volume, rede, ícones de programas em execução.
  • Botão Iniciar: no canto esquerdo (Windows 10) ou central (Windows 11).

3.2. Gerenciador de Tarefas (Ctrl + Shift + Esc)

  • Processos: lista de aplicativos e processos em execução.
  • Desempenho: uso de CPU, memória, disco, rede.
  • Histórico de aplicativos: uso de recursos por aplicativo.
  • Inicializar: programas que iniciam com o Windows.
  • Usuários: sessões ativas.
  • Detalhes e Serviços: informações mais técnicas.
  • Fechar programa: selecionar um aplicativo e clicar em "Finalizar tarefa".
💡 Dica: Ctrl + Alt + Del também abre o Gerenciador de Tarefas (selecionando a opção).

MÓDULO III – JANELAS, PAINEL DE CONTROLE E LIXEIRA

4.1. Janelas (Navegação)

  • Componentes: barra de título, botões de minimizar, maximizar/restaurar e fechar.
  • Menus: Arquivo, Editar, Exibir, Ferramentas, Ajuda (em aplicativos).
  • Barras de ferramentas: ícones para ações rápidas.
  • Painéis: lista de arquivos, pastas, pré-visualização.
  • Caixa de pesquisa: localizar arquivos ou pastas rapidamente.
  • Caixas de marcação (checkboxes): selecionar itens.
  • Navegação: atalhos Alt + Tab (alternar janelas) e Win + D (mostrar área de trabalho).

4.2. Painel de Controle

  • Central de configurações: Sistema, Hardware, Rede, Contas de usuário, Programas.
  • Modos de exibição: Categoria, Ícones grandes/pequenos.
  • Desinstalar programas: remover aplicativos.
  • Configurações de energia: ajustar plano de energia.

4.3. Lixeira

  • Função: armazena arquivos excluídos temporariamente.
  • Restaurar: recuperar arquivos excluídos.
  • Esvaziar: remover permanentemente.
  • Propriedades: espaço reservado, opções de exclusão.
  • Atalho: Shift + Delete exclui permanentemente, sem ir para a Lixeira.

MÓDULO IV – ARQUIVOS, PASTAS, ÍCONES E ATALHOS

5.1. Operações com Arquivos e Pastas

  • Localizar: usar a pesquisa do Windows ou o Explorador de Arquivos.
  • Copiar: Ctrl + C, Colar: Ctrl + V.
  • Recortar: Ctrl + X (move o arquivo).
  • Excluir: Delete (envia para a Lixeira).
  • Renomear: F2 ou botão direito → Renomear.
  • Criar: botão direito → Novo → Pasta / Arquivo.
  • Criar atalho: botão direito → Criar atalho.
  • Abrir: duplo clique ou Enter.
  • Abrir com: escolher um programa específico para abrir o arquivo.
  • Editar: abrir para edição.
  • Enviar para: enviar para dispositivo removível, e-mail, etc.
  • Propriedades: informações sobre o arquivo/pasta (tamanho, local, atributos).
  • Criptografar: proteger o arquivo com senha (via propriedades → Avançado).
  • Ocultar: marcar como oculto (propriedades → Oculto).

5.2. Ícones e Atalhos

  • Ícone: representação gráfica de um arquivo, pasta ou programa.
  • Atalho: ícone com uma seta no canto inferior esquerdo.
  • Criar atalho: botão direito → "Criar atalho" ou arrastar com Ctrl + Shift.
  • Função: aponta para o local original do arquivo.
💡 Dica: Shift + Delete exclui permanentemente. Ctrl + Z desfaz a última ação.

MÓDULO V – NOMES VÁLIDOS E DICAS FINAIS

6.1. Nomes Válidos para Arquivos e Pastas

  • Caracteres permitidos: letras (A-Z, a-z), números (0-9), espaços, hífen (-), sublinhado (_), ponto (.), vírgula (,), parênteses, colchetes.
  • Caracteres proibidos: \ / : * ? " < > |
  • Extensões: parte após o ponto (ex: .txt, .docx, .pdf).
  • Tamanho máximo: 255 caracteres (incluindo o caminho completo).
  • Diferença entre maiúsculas e minúsculas: o Windows não diferencia (ex: "Arquivo" = "arquivo").
