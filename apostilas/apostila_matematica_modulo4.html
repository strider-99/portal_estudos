MÓDULO I – EXPRESSÕES ALGÉBRICAS

2.1. Monômios

Monômio é o produto de um número (coeficiente) por uma ou mais letras (parte literal). Ex: 3x², −5ab, 7.

  • Grau de um monômio: soma dos expoentes da parte literal. Ex: 3x²y tem grau 3.
  • Monômios semelhantes: mesma parte literal. Ex: 3x² e −5x².

2.2. Polinômios

Polinômio é a soma algébrica de monômios. Ex: 3x² + 2x − 5.

  • Grau do polinômio: maior grau dos monômios que o compõem.
  • Termo independente: monômio sem parte literal.

2.3. Operações com Polinômios

  • Adição/Subtração: reduza os termos semelhantes.
  • Multiplicação: distributiva. Ex: (x+2)(x+3) = x² + 3x + 2x + 6 = x² + 5x + 6.
  • Divisão: divide-se cada termo do dividendo pelo divisor (para monômios).

📌 Exemplo: Simplifique 5x² + 3x − 2x² + 4x − 7:

  • Termos semelhantes: 5x² − 2x² = 3x²; 3x + 4x = 7x; −7
  • Resultado: 3x² + 7x − 7
✅ Dica: Para somar ou subtrair polinômios, sempre agrupe os termos semelhantes antes de calcular. Isso evita erros.
⚠️ Pegadinha: Sinais negativos antes de parênteses! Ex: −(2x − 3) = −2x + 3 (o sinal de menos troca TODOS os sinais internos).

MÓDULO II – PRODUTOS NOTÁVEIS E FATORAÇÃO

3.1. Produtos Notáveis

NomeFórmula
Quadrado da soma(a + b)² = a² + 2ab + b²
Quadrado da diferença(a − b)² = a² − 2ab + b²
Produto da soma pela diferença(a + b)(a − b) = a² − b²
Cubo da soma(a + b)³ = a³ + 3a²b + 3ab² + b³
Cubo da diferença(a − b)³ = a³ − 3a²b + 3ab² − b³

📌 Exemplo: (x + 5)² = x² + 2·x·5 + 5² = x² + 10x + 25

📌 Exemplo: (3a − 2)(3a + 2) = (3a)² − 2² = 9a² − 4

3.2. Fatoração

Fatorar é transformar uma expressão em produto. Principais casos:

  • Fator comum em evidência: ax + ay = a(x + y)
  • Agrupamento: ax + ay + bx + by = a(x + y) + b(x + y) = (x + y)(a + b)
  • Diferença de quadrados: a² − b² = (a + b)(a − b)
  • Trinômio quadrado perfeito: a² + 2ab + b² = (a + b)²; a² − 2ab + b² = (a − b)²
  • Soma/diferença de cubos: a³ ± b³ = (a ± b)(a² ∓ ab + b²)

📌 Exemplo: Fatore x² − 9:

  • É uma diferença de quadrados: x² − 3²
  • x² − 9 = (x + 3)(x − 3)
✅ Dica: Reconhecer produtos notáveis economiza tempo. Decore as fórmulas e pratique a identificação.
⚠️ Pegadinha: (a + b)² ≠ a² + b²! Esse é o erro mais comum em provas. Nunca esqueça o termo 2ab do meio.

MÓDULO III – EQUAÇÕES E INEQUAÇÕES DO 1º GRAU

4.1. Equações do 1º Grau

Forma geral: ax + b = 0, com a ≠ 0. A solução é x = −b/a.

📌 Exemplo: Resolver 3x + 5 = 20:

  • 3x = 20 − 5 = 15
  • x = 15/3 = 5

4.2. Equações com Frações

Multiplique todos os termos pelo MMC dos denominadores para eliminar as frações.

📌 Exemplo: Resolver x/2 + x/3 = 10:

  • MMC(2,3) = 6. Multiplicando tudo por 6: 3x + 2x = 60
  • 5x = 60 → x = 12

4.3. Inequações do 1º Grau

São resolvidas como equações, mas com atenção ao sinal:

  • Ao multiplicar ou dividir por número negativo, o sinal da desigualdade se inverte.

📌 Exemplo: Resolver −2x + 4 > 10:

  • −2x > 10 − 4 = 6
  • Dividindo por −2 (negativo): x < −3
✅ Dica: Sempre isole a incógnita em um dos lados da equação/inequação e simplifique passo a passo.
⚠️ Pegadinha: Na inequação, esquecer de inverter o sinal ao multiplicar/dividir por número negativo é o erro mais comum. Sempre verifique o sinal do coeficiente de x.

MÓDULO IV – SISTEMAS DE EQUAÇÕES DO 1º GRAU

5.1. Conceito

Um sistema de equações do 1º grau com duas variáveis possui duas equações e duas incógnitas. Forma geral:

  • a₁x + b₁y = c₁
  • a₂x + b₂y = c₂

5.2. Métodos de Resolução

  • Substituição: isolar uma variável em uma equação e substituir na outra.
  • Adição (ou eliminação): somar as equações após multiplicá-las para eliminar uma variável.

📌 Exemplo (substituição): Resolver:

  • x + y = 10
  • x − y = 4

Somando as equações: 2x = 14 → x = 7. Substituindo: 7 + y = 10 → y = 3.

Solução: (7, 3)

5.3. Interpretação Gráfica

Cada equação representa uma reta. A solução do sistema é o ponto de interseção das retas.

  • Sistema possível e determinado: retas concorrentes (uma solução).
  • Sistema possível e indeterminado: retas coincidentes (infinitas soluções).
  • Sistema impossível: retas paralelas (nenhuma solução).
✅ Dica: Em problemas de contexto (ex: "quantos carros e motos há em um estacionamento"), monte o sistema com base nos dados e resolva pelo método da adição, que costuma ser mais rápido.
⚠️ Pegadinha: Cuidado com problemas em que as unidades estão misturadas (ex: valores em reais e centavos, ou horas e minutos). Uniformize antes de montar o sistema.

MÓDULO V – EQUAÇÕES DO 2º GRAU

6.1. Forma Geral

ax² + bx + c = 0, com a ≠ 0.

6.2. Fórmula de Bhaskara

Para resolver, use:

  • Δ (delta): Δ = b² − 4ac
  • Raízes: x = (−b ± √Δ) / 2a

6.3. Análise do Discriminante (Δ)

  • Δ > 0: duas raízes reais e distintas.
  • Δ = 0: uma única raiz real (raiz dupla).
  • Δ < 0: nenhuma raiz real.

📌 Exemplo: Resolver x² − 5x + 6 = 0:

  • Δ = (−5)² − 4·1·6 = 25 − 24 = 1
  • x = (5 ± √1) / 2 = (5 ± 1)/2
  • x₁ = 6/2 = 3; x₂ = 4/2 = 2
  • Raízes: 2 e 3

6.4. Relações de Girard (Soma e Produto)

  • Soma das raízes: S = −b/a
  • Produto das raízes: P = c/a

Útil quando se conhece a soma e o produto das raízes (ex: montar uma equação do 2º grau a partir das raízes).

6.5. Equações Incompletas

  • b = 0: ax² + c = 0 → x² = −c/a → x = ±√(−c/a)
  • c = 0: ax² + bx = 0 → x(ax + b) = 0 → x = 0 ou x = −b/a
✅ Dica: Antes de aplicar Bhaskara, verifique se a equação é incompleta (b=0 ou c=0). Nesses casos, resolva por fatoração ou isolamento, que é mais rápido.
⚠️ Pegadinha: Sempre identifique os coeficientes a, b e c com seus sinais. Um erro clássico é esquecer que "−5x" significa b = −5. Além disso, cuidado com o sinal do Δ: se b é negativo, b² é positivo.
